# V8 舒适阅读设计规范（默认值）

核心：**左边是一本书，右边是一本随手翻的 PPT；不是两套同步的幻灯片。**

## 桌面

- 左侧 62% / 右侧 38%，支持拖动宽度；左右垂直滚动容器彼此独立。
- 左侧文章内收窄阅读列，`max-width:720px; margin:auto`；视觉上宁可两侧留白，也不要让大段文字横跨整个屏幕。
- 中文主体 17–19px，建议 18px、行高 1.82，正文段间距 1.1em；主文字深海军蓝 `#1d2b43`，次级文字 `#61728a`。
- 标题最大 25–30px，小标题 19–21px；不要为每两句话加一个“STEP X”或卡片。
- 公式清楚居中，前一句是引导，后一句解释；对很长的数学表达式让公式容器可横向滚动，但页面整体不溢出。
- 实验和正式练习可使用一层柔和边框、淡灰底；普通解释、例题、重点句多数使用原生排版（p、h、blockquote/mark-like emphasis）。
- 不用彩虹色/大型 badge 装饰课程各层级；不同颜色只用于计算高亮、正确/错误反馈、定位提示等有意义区分。
- 导航克制：页码和章节切换存在即可，不在每一段顶部重复显示一套完整面板。

## 右侧 PDF

- 纵向连续渲染**整个原 PDF**，高保真保留示意图；按需/懒加载提高性能。阅读滚轮和触控板自然上下翻。
- 页面中性底色，页间留 10–18px；允许跳页、缩放、上一页参考；展示当前接近页面。
- 点击左侧章节**不得自动移动 PDF**。只有“查看对应课件页”按钮主动定位。
- 可选准确的页内重点区域高亮，必须有实际依据和坐标，不能猜位置。任何高亮都能关闭，且不替代 PDF 原图。

## 手机

- 不把两栏挤在 375px 屏幕里；改为两个 Tab「讲解」「课件」，切换保留两侧滚动位置。
- 字体默认 16–17px，行高约 1.76；控制按钮可点、交互矩阵不超宽、公式可水平滚动。
- 公式演算与数字表格保持阅读性，必要时使用水平滚动只影响内部元素。

## 反模式

- 五张讲解卡、知识链卡、步骤卡层层嵌套。
- 每页同样格式填满固定字数、每页强制一题。
- “点击继续讲解”来逐段解锁文字。
- 左侧换章节同时强制右侧跳页。
- PDF 图变成低质量模糊缩略图，或只提供本批讲解页而漏掉整份原 PDF 的其余页面。
- 大段高饱和蓝底摘要盖住正文。
