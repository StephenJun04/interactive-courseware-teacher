# 自适应练习设计与判分

以下是教学设计目标。当前内置阅读器支持三种题型与两级错误反馈，综合题统一判分，`remedial` 只展示静态追问；若要求逐小问反馈、追问判分或跨讲次恢复加练，需要在当前任务副本中扩展并验证。字段及现有边界见 [构建与数据格式](build-and-schema.md)。

## 分层出题，不机械定量

按知识难度、错误风险与需要的迁移量动态配置：

| 类型 | 建议题量 | 重点 |
| --- | --- | --- |
| 封面 / 章节目录 / 已讲知识重复展示 | 0 | 可以只有一句复习提示 |
| 轻量定义与背景 | 0–1 | 核心理解即可 |
| 新的关键概念 | 1–2 | 直觉、反例、常见误解 |
| 公式计算、边界条件、多步模型 | 2–4 | 带数字、解释、改变参数 |
| 相关知识收束 | 1–3 道组合题 | 需要跨页迁移而非背题 |

题量由**教学需要**而非 ppt 页数决定，简单页不必填题。不能让题目用到还没解释的公式；如果要“预测下一页”，以开放思考提问而非正式判分题。

## 题型

- 单选 `single_choice`：清晰唯一答案，错误选项对应真实误区，不是语义陷阱。
- 数字输入 `numeric`：真实计算、容许误差 `tolerance`。给计算目标、单位与必要假设。
- 多问综合 `multi_part`：每问可独立反馈；例：输出长宽→参数量→乘法次数→Stride 改变什么/不变什么。
- 可选追问 `remedial`：只有学生答错时展开，内容针对错误概念，**改对原题也不应抹去已触发的加练**。

## 反馈分层

第一次错：说明“应该重新核查哪一个概念”，不要马上把完整数值答案全给了。
第二次错：给逐步解法。学生输入正确：解释为什么对，并连到对应课件页/公式。

## 核对算法

对数字题必须自己先手算或程序复核。
卷积参数量（含每输出通道一个 bias）：`(F*F*Cin + 1) * Cout`。
卷积输出尺寸（单轴，dilation=1）：`floor((N + 2P - F) / S) + 1`；要求 `N+2P >= F`。
乘法（忽略边界优化/稀疏）：`M_h * M_w * F_h * F_w * C_in * C_out`。
这些是教师数学背景，不自动等同于任何一页课件的陈述；若课件采用其他约定，应以课件版本说明差别。
