# 交互实验策略

## 首要判断：需要可视化吗？

必须能回答“这个参数变了会看到什么因果变化？”如果没有，不要造实验。可以先用一个数字例子或图。

## 内置实验

### `convolution`
- 当前内置实验由 `config` 指定固定输入矩阵，卷积核可编辑；点击输出位置后计算并高亮对应窗口，展示**每项乘积与求和**。若需要学生编辑或选择输入，需在任务副本中扩展。
- 说明这是深度学习实践中的 cross-correlation（卷积核未翻转），不与纯数学卷积记号混淆。
- 不得把换权重后的输出预制为 GIF；每次由 JS 真实计算。

### `output_shape`
- 滑块调节 `N, F, P, S`，展示补零后尺寸、最大窗口合法起点、步长序列、最终 `M`。
- 不仅展示公式数值，还解释为什么 +1、为什么 `2P`、为什么需要 `floor`。
- 可延伸到参数量和乘法次数，但须说明通道数。

## 其他课程扩展建议（生成器当前并非内置）

- 梯度下降：真实计算 `J(theta)`、梯度、学习率、连续更新迭代。
- Backprop：计算图每条边的数值、局部导数、链式法则传播。
- Attention：从 token embedding 计算 Q/K/V → QK^T → scale/mask → softmax → weighted sum，直观展示矩阵形状。
- RNN/LSTM：时间步状态和门控值、梯度随序列长度衰减。

针对其他知识，需要新实现真实数值实验；**不得因 HTML 模板里只有 CNN 交互就把别的章节强行变成 CNN 交互**。
