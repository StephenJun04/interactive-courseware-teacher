# 教学写作：补课件真正省略的推理

## 先分类，再写正文

范围内每页必须审阅并有原始页码对应，但不必都有长篇精讲。根据课件自足程度、前置知识缺口、错误风险与迁移要求，选择：

| 深度 | 识别依据 | 讲解方式 |
| --- | --- | --- |
| 略读 | 课件已清楚表达；目录、背景列表、无新步骤的重复页 | 简述结论或本页变化，指向原页；通常无题、无实验 |
| 讲清 | 一个新概念或少量隐含推理 | 补为什么与关键连接，必要时一个例子或反例 |
| 精讲 | 核心机制、多步推理、维度/目标/状态变化、容易形成错误心智模型 | 解释关键假设与中间步骤，按需推导、手算、误区、实验和练习 |

简短的 Attention 公式可能需要精讲；详细的术语列表也可能只需略读。分类依据必须来自实际页面与已讲知识，不能假装知道学生背景。用户提出更深或更浅要求时调整。

## 按页对应，按概念建立知识链

- 页面图像中的箭头、表格、代码、公式与动画变化都算内容，不能只读提取文本。
- 覆盖表保留物理页码、不同的印刷编号、深度与简短理由；范围外页面标记“仅原文参考”，不能声称已精讲。
- 相邻页面重复一个机制时，在关键页建立完整解释，后续页只补新增步骤、条件或数值变化；每页仍保留独立 lesson 与对照位置。
- 已解释的前置知识引用其页码；首次出现但理解当前内容必需的前提短补。不要每讲从概率、线性代数或 Python 基础重新开始。

## 精讲时选择真正有用的内容

考虑：它解决什么问题；直觉怎样落实到公式/代码；变量与张量怎样变换；哪一步课件省略了；一个最小例子能否复算；误区与适用条件是什么。

这些是可选择的解释工具，不是每页必须出现的六个段落。普通内容写成连贯文章，必要时使用小标题、公式、代码或表格。自然的承接即可，不强制每页留下悬念。

推导目标是让学生理解或自己重建关键结果。课件已解释清楚或此前已推导的辅助公式，不必再次完整展开。区别模型原理与实现细节；没有具体实现材料时，不猜代码、库行为或版本。

## 来源与准确性

课件原意、教师补充、简化假设与疑似笔误用可见 note 区分。不要悄悄改写原公式或引用不存在的页面。

举例可以自行设计，但必须标记教学例子，独立复核数字与形状；不能将简化模拟描述成真实模型测量或论文结果。当前 API/库行为确需查证时只核对相关官方材料，稳定的课内推导不为了凑参考链接额外检索。

## 连读自查

学生能否理解课件省略的关键一步？重复内容是否只讲新增部分？略读页是否仍有遗漏的新概念？增加的例子、推导与实验是否确实帮助当前章节？不满足时调整相关段落，而不是继续加长全文。
