# 上线前质量闸门

## 教学内容

- [ ] 范围内每页有完整对应（封面/目录可简述），图片/表格/连续动画也检查了。
- [ ] 页码完整对应，深度有依据；略读页没有遗漏隐含难点，重复页只解释新增内容。
- [ ] 按概念自然衔接，不机械复述每页或强制设置下一页悬念。
- [ ] 新的关键公式解释必要符号、维度与假设；需要数值例子时能复算，不重复推导已讲内容；课件原意、教师拓展分明。
- [ ] 所有自编数值题、综合题由程序或人工独立复核。
- [ ] 简单页可以 0 题，难页多题，不强制平均；答错反馈有针对性。

## 视觉与交互

- [ ] 普通解释像连续文章，不是一堆文字卡片；实验和正式练习才独立成块。
- [ ] 左侧修改章节，右侧 PDF 位置不变；主动“对照本页”按钮才跳转。
- [ ] PDF 整份（非只有讲解页）连续滚动，能跳页、缩放，手机能切 Tab。
- [ ] 字体/公式不溢出，按钮可点击；滚动长文章舒适。
- [ ] 实验真实重新计算，动态输出与数学一致；空输入/极限参数正确处理。
- [ ] 题目提交、错题提示、重复作答、加练触发、笔记本地保存均检查。
- [ ] 静态离线 HTML 无任何必需的网络请求；若采用外部库明确给出离线替代。

## 核验方式

- 静态校验：`python scripts/check_lesson.py ...`。
- 浏览器手测/Playwright：P1、章节中间、最后一页；不同屏宽 375px / 768px / 1440px，至少一种真实点击和一次滚动。
- 对数学计算型实验，给定已知测试数据比对值，不只看 UI 有变化。
- 报告客观范围与尚未测试内容；不要虚构“10/10”“全部已验证”。

## 检查范围与重做规则

首次交付：完整检查指定范围的内容与所有新增实验；框架检查按首/中/末讲及窄屏执行一次。续做：复用已验证且未变化的框架证据，核对新增内容、公式、答案和实验；修改导航、布局或持久化则重跑对应框架检查。通过后即可交付，不因没有影响结果的外观调整重复全套检查。
